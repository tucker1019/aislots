# AG9 幸运豹服务端

独立规则 `fortune_leopard_v1`。三列三行五线；普通结果与锁定重转互斥。重转允许目标普通图标、百搭、空白；旧图标锁定，一轮没有新增或填满后结束，只在末帧入账。

九格全部参与中奖触发十倍，允许三条横线分别为不同图标。全盘百搭为总投注2500倍。原始表及骨架桶键已经包含十倍；奖金按 `实际总投注 × 原始倍率 ÷ 5` 精确计算并取整。仅支持普通投注模式。

## 数值与候选

数值初值来自Lua1021，零档权重折算为模式中奖率。四个不可达重转档已按用户确认方案替换为相邻可达档，保持中奖率、触发率及平均奖金，总初始返还率约96.85220121%。规则和修正明细见[数值规则](../../../../slot_math/docs/ag9-rules.md)。

普通1535条骨架，覆盖137/137档；重转252条，覆盖25/25档。空奖不依赖结果库，运行时约束生成。普通补空每格排除会新增中奖的候选后抽取一次，没有结果重摇、回溯、换倍率或借邻档。

第一帧扣款一次，最后一帧支付最终奖金。请求重试、恢复和回放使用已保存的结果，不重新随机；进行中的整局继续使用原发布版本。`gameData`包含目标图标、锁定格、新增格、十倍标记、中奖线及投注基准，协议定义见`protos/game_ag9.proto`。
