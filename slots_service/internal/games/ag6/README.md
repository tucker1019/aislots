# AG6 金鼠服务端

独立规则模块 `fortune_mouse_v1`，不继承 AG4 的锁格填充流程或 AG5 的八次特殊转。先按特殊触发率选择普通或特殊模式。普通模式按中奖率判断正奖，再按普通倍率表抽倍率；特殊模式按整段最终倍率表抽一次正奖。桶内骨架数量不决定倍率概率。

## 当前本地资源

`testdata/deployments/2026-11-15-ag6/AG6` 保存四份配置及两套经过 Go 逐条重验的骨架库。普通覆盖312/312、特殊覆盖267/267，分别937条和802条，含零权重原始5000的全盘百搭展示骨架。初始普通中奖率28%、特殊触发率1.4%、特殊整段必中奖；全盘百搭大奖权重仍为0。

`configs/server.test.json` 已注册该本地快照；`configs/bets.test.json` 配置五线、金额精度2、投注等级上限10。仅本地测试配置接入，线上配置需要独立选择发布版本。

在 `slots_service` 下创建新的不可变快照：

```sh
go run ./cmd/ag6-publish \
  -config ../game_configs/AG6 \
  -base ../game_libraries/AG6/base/2026-11-14T17-46-24-753Z-540bb2c0 \
  -free ../game_libraries/AG6/free/2026-11-14T17-46-24-803Z-12bfbdd6 \
  -out /新的发布目录/AG6
```

命令核对候选格式、数据哈希和盘面配置，按当前倍率表独立验奖并检查全部正权重档。快照保存配置和库哈希、规则版本、覆盖和候选来源；原候选保持不变。目标目录已存在则拒绝覆盖。服务启动会重新检查清单、哈希、覆盖和每条骨架，缺档直接报错。

## 空奖与一次补空

普通空奖从九个空位开始；特殊空奖固定零基3、4、5为百搭7，其余六格为空。按列从上到下补六种普通符号，先排除新增中奖线的候选，再按形态权重抽一次。每个空位只赋值一次，不重摇、不回溯、不换骨架或倍率。每格最多四条线、六种普通候选保障可补齐；两个百搭加空格的不可补形态在消耗随机数前拒绝。

中奖骨架只固定中奖格，特殊骨架另固定中列三个百搭。补空后逐线奖、中奖格、全盘百搭标识和原始倍率必须完全不变。空奖实时生成，不从零奖桶抽取。随机源错误或一致性断言失败直接报错。

## 特殊过程与资金

特殊模式先抽最终正倍率和对应骨架，再按1019策略选择前段零奖数量：基础1～4的权重149、600、300、151，加上原始倍率区间对应的1～4。最终展示2～8个零奖盘面及一个中奖盘面。每帧中列均为百搭，左右列重新生成。第一笔正奖即结束，不追加其他中奖帧。

每笔投注在一次 Draw 中生成完整结果，保存后按帧消费。只在第一帧扣款，最后帧一次入账，其他帧金额为0。原始倍率除5得到总投注倍率；全盘百搭支付原始5000，即总投注1000倍，替代线奖。原始1000是独立合法非全盘百搭档。

金额采用大整数中间计算，按总线奖累计取整分配逐项金额，合计严格等于最终帧入账；避免分线取整丢失尾数。金额溢出报错。`gameData.replay.payouts` 保存这些实付明细，私人和公开回放直接复用。

状态只有已完成局序号，跨版本后可继续下一局。进行中的整段特殊功能由平台投注单固定原版本和完整结果；重试、重启恢复、历史和公开回放读取已保存帧，不重新抽图标，不提前返回未来帧。

## 接口和验证

沿用已有登录、bets、state、spin、历史、分享回放和自动整局接口，无新增对外接口。普通帧 `mode=base`，特殊帧 `mode=respin`；`freeRemaining=0`、`triggeredFree=false`，特殊进度使用 `gameData.stageIndex/stageTotal/stagesRemaining`。帧字段见[接口文档](../../../docs/client-api.md#ag6-本地接口)；[联调样例](../../../testdata/ag6-client-examples.json)由服务端真实验奖与帧构造代码生成，固定结果用例不代表真实开奖权重。

```sh
go test ./...
go vet ./...
go test -race ./...
# 真实数据库测试使用独立临时 schema，结束后自动清理。
AISLOTS_TEST_DATABASE_URL='本地测试数据库连接' go test -race -count=1 ./internal/infrastructure/postgres
```

TypeScript 数值工具导出583组验奖、补空对照及64组特殊长度边界：`node tools/export_ag6_parity.mjs`，需Node22及已安装的slot_math依赖。样例更新：`AG6_WRITE_EXAMPLES=1 go test ./internal/games/ag6 -run TestClientExamples`。其他测试覆盖所有候选逐条补空、一次抽取、配置隔离、零权重大奖、金额取整、不可变发布、损坏拒绝、幂等、恢复、版本固定、HTTP及自动结算。
