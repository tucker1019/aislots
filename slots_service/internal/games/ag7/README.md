# AG7 金牛服务端

独立规则模块 `fortune_ox_v1`。盘面三列3、4、3格、十线，按列从上到下编号1～10。普通和特殊二选一，倍率表决定奖金，桶内骨架数量只影响图形。

满盘普通图标混百搭统一按该普通图标十条线乘十倍；全盘纯百搭支付总投注2000倍。全部加成已包含在原始最终倍率中，金额为 `总投注 × 原始倍率 ÷ 10`，结算时不重复乘十。总投注10元时，橘子混百搭满盘支付500元，全盘百搭支付20000元。

## 本地资源

`testdata/deployments/2026-11-15-ag7/AG7` 为独立不可变快照，普通232条骨架覆盖77/77档，特殊78条覆盖26/26档。普通原始20000档的初始权重为0；特殊左右六格必须为普通图标，因此不加入纯百搭档。初始普通中奖率29%、特殊触发率0.7%，理论返还率约97.003563%。

`configs/server.test.json`、`configs/bets.test.json` 已注册本地版本及十线投注。生产配置单独选择发布版本。

创建新的不可变快照，在 `slots_service` 下执行：

```sh
go run ./cmd/ag7-publish \
  -config ../game_configs/AG7 \
  -base ../game_libraries/AG7/base/2026-11-14T19-28-46-249Z-38141131 \
  -free ../game_libraries/AG7/free/2026-11-14T19-28-46-268Z-28265623 \
  -out /新的发布目录/AG7
```

发布器及启动加载逐条独立验奖、验证哈希和正权重覆盖。缺档或损坏直接报错，不借用其他倍率、不改表、不覆盖候选及已有快照。

## 过程与结算

特殊每个盘面的左右六格全部为同一种普通图标，三列均重新旋转，不锁格。先抽最终正奖及骨架，再按旧1023实际区间生成2～8次空奖，最后一帧中奖即结束。空奖次数权重100、500、1000、2500、3200、2300、400，总和10000；不存在表尾的额外次数。

普通骨架固定中奖格，特殊另固定左右六格，满盘奖固定十格。空奖实时生成；补空逐格排除新增中奖的普通候选，每格只抽一次，不重摇、不回溯、不换骨架。特殊空奖先选一次左右共同图标，再补四个中列空位。

一次 Draw 生成完整结果并保存，第一帧扣一次投注，最后帧一次派奖。中间帧金额0；已保存帧用于重试、重启恢复、私人及公开回放，未结算的未来帧不提前暴露。进行中投注固定旧版本，完成后的序号状态允许切换新版本。

金额使用大整数中间计算及累计取整，逐项实付之和等于最终入账，溢出直接报错。全盘百搭是一项替代大奖，其他满盘奖为十项已经乘十的线奖。

## 接口与验证

沿用既有登录、bets、state、spin、历史、分享和自动整局接口，无新增对外接口。普通 `mode=base`，特殊 `mode=respin`。`lockedCellIds` 始终为空；`sharedCellIds=[1,2,3,8,9,10]` 和 `sharedSymbolId` 表示同盘面六格相同，不表示跨帧保留。专用进度、满盘信息及金额说明见[接口文档](../../../docs/client-api.md#ag7-本地接口)。
