# AG5 金兔服务端

`fortune_rabbit_v1` 是独立游戏模块。普通及特殊每转先按对应中奖率判断，再按 `base.json` / `free.json` 的倍率权重选奖，最后从该倍率桶抽一条骨架。桶内条数只影响形态，不影响倍率概率。普通奖先结算，再独立触发八次特殊转；每次特殊转独立、当转清空、当转派奖。整局普通加特殊共用总投注5000倍封顶。

## 配置与本地发布

数值输入见 `game_configs/AG5`，已保存的普通中奖率0.288、特殊单转中奖率0.36、触发率0.006保持原值。当前本地发布为 `slots_service/testdata/deployments/2026-11-15-ag5/AG5`，普通覆盖1440/1440、特殊覆盖2635/2635。`configs/server.test.json` 已注册该快照，`configs/bets.test.json` 使用10线投注策略。

在 `slots_service` 目录生成新的不可变本地发布：

```sh
go run ./cmd/ag5-publish \
  -config ../game_configs/AG5 \
  -base ../game_libraries/AG5/base/2026-11-14T08-53-17-412Z-3bb98183 \
  -free ../game_libraries/AG5/free/2026-11-14T08-53-18-079Z-e260cd78 \
  -out /新的发布目录/AG5
```

命令独立验奖、检查正权重倍率覆盖及可补齐性，将当前四份数值文件和两个库写入新目录；原候选及 manifest 不变。候选可能早于当前中奖率调整，只有按当前配置重验后才能绑定为新发布。服务启动再次检查配置哈希、库哈希、玩法版本、覆盖和每条骨架。目标目录已经存在时拒绝发布。后续更新应增加新发布并保留旧版本，供正在进行的投注完成。

## 一次补齐

`fill.go` 与数值工具 `fortuneRabbit.ts` 使用同一规则：先排除会新增中奖线的候选，再按剩余普通图标权重抽取一次。按格顺序只赋值一次，保持骨架固定元素；结束验奖只作断言，错误直接上报。没有重摇、重抽、回溯或替换倍率、骨架的路径。

发布拒绝不完整的两个百搭线；正权重普通符号数必须大于每格最多所在线数。当前六种普通图标、每格最多四条线，每条线最多排除一种，所以每格至少剩两种候选。

空奖先从 `二项分布(4,奖励生成概率)` 抽一次奖励数量，再从未占用格集合无放回抽位置，按奖励面值生成权重抽面值。普通剩余格用同一约束补齐，特殊剩余格留0。数量始终0～4，不会产生奖励奖金。该分布只控制空奖外观；中奖率和倍率仍由数值参数决定。特殊中奖骨架保留全部奖励，空位保持0。

## 结算、状态和回放

一次付费流程生成一个内部结果，包含普通转及最多八次特殊转的逐帧派奖计划；数据库一次保存，后续 spin 消费下一帧。第一帧扣一次投注，每帧支付当前转奖金，最后一帧提交下一局序号。平台通用结算层不包含 AG5 判奖逻辑。

原始倍率除10得到总投注倍率。金额使用任意精度整数进行中间计算，按整局已付原始倍率累计取整，再以差额逐转入账，防止小额投注丢失尾数；超出 int64 的金额报错。封顶时仅支付剩余额度并结束，盘面及原始中奖奖项保持原样。

明细按线号顺序、再按奖励格顺序分配实付。`gameData.replay.payouts` 保存逐项实付，合计精确等于当前帧入账；封顶回放直接复用这些明细。状态、请求重试、私人及公开回放读取已保存帧，不生成随机数，不暴露未结算盘面。

客户端字段见 [接口文档](../../../docs/client-api.md#ag5-本地接口)，完整固定结果样例见 [联调样例](../../../testdata/ag5-client-examples.json)。样例使用专用测试表，不代表当前倍率权重。

## 验证

```sh
go test ./...
go vet ./...
go test -race ./internal/games/ag5 ./internal/games ./internal/application/play ./internal/infrastructure/postgres
```

数据库集成测试需设置 `AISLOTS_TEST_DATABASE_URL`，使用现有测试帮助函数创建独立随机 schema，结束后清理。覆盖一次扣款、逐转派奖、封顶明细、重试、重启、版本固定、状态恢复、分页历史、公开回放和整局自动结算幂等。

数值工具导出的验奖与补齐样例用于跨语言核对：`node tools/export_ag5_parity.mjs`（Node22，已安装 slot_math 依赖）。重新生成接口样例运行 `AG5_WRITE_EXAMPLES=1 go test ./internal/games/ag5 -run TestClientExamples`；普通测试会核对样例是否过期。
