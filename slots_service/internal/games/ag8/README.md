# AG8 金龙服务端

独立模块 `fortune_dragon_v1`，三列三行、五条线，百搭替代、每线最高奖、线奖相加。普通结果与八次免费二选一。免费每转独立，倍率按和计算，八次全空完整保留。

`buyMode`省略或1表示普通投注，2表示五倍投注；五倍扣款使用独立两表及中奖率，奖金基准不提高。普通奖金为`实际扣款×盘面倍率×底部倍率÷5`，五倍模式除以25。原始表和骨架桶均尚未乘底部倍率。

## 开奖与持久化

每次付费Draw一次决定整个普通结果或免费序列，包括盘面、底部倍率及封顶后的实际阶段数量。正奖按中奖率和倍率权重抽取，再选同档骨架并逐格补齐；零奖直接逐格构造。每格从普通图标中排除新增中奖的候选后抽一次，无重摇、回溯或换倍率。

第一帧只扣款一次，每次免费逐帧入账。大整数中间计算，累计原始奖金取整后做差分；每线金额之和等于本帧实付。整局上限是实际扣款2500倍，末帧仅支付剩余额度，并取消剩余免费。八次全空仍有八帧。

请求收据及投注记录固定实际扣款和投注模式，同一请求或进行中免费更换金额、模式会报冲突。保存的结果用于重试、恢复、回放；查询不重新随机，尚未消费的未来帧不会提前暴露。进行中锁定旧发布版本，完整结束后可以切换新版本。

公共 `spin` 支持两种投注方式，`bets.buyModes`提供模式和扣款倍数。旧准备/推进接口及内部自动整局沿用普通投注；内部自动整局可完整处理AG8八次免费。客户端字段见[接口说明](../../../docs/client-api.md#ag8-本地接口)，固定结果见[七组联调样例](../../../testdata/ag8-client-examples.json)。本模块没有修改客户端。
