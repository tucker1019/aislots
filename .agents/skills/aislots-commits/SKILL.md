# aislots 提交规范

提交标题采用 `[模块] 中文变更说明`，按改动所属目录选择前缀：

| 目录 | 提交前缀 |
| --- | --- |
| `client/` | `[游戏客户端]` |
| `slots_service/` | `[游戏服务端]` |
| `game_configs/`（用户称 `game_config`） | `[游戏配置]` |
| `game_libraries/` | `[游戏盘面库]` |

以上前缀替代旧的 `[客户端]` 和 `[服务端]`。目录名称以仓库实际路径为准，不为匹配提交前缀而重命名目录。

涉及多个模块时按模块分别提交，相关文档和测试随对应模块提交。只暂存本次用户要求的改动，保留其他未提交工作。

示例：

- `[游戏客户端] 修复分享回放的重播交互`
- `[游戏服务端] 增加交易回放分享接口`
- `[游戏配置] 调整AG1免费局权重`
- `[游戏盘面库] 更新AG1普通和免费盘面库`

此规范只约定提交分类与标题，不额外授予提交、推送或发布权限。
