# 异步按钮状态

适用于登录、注册、提交、领取、保存、刷新、加载更多等点击后请求接口的按钮。只约束交互表现，不改变接口、业务权限、幂等规则或已有最短加载时长。

- 请求中按钮只显示一个居中的小圆圈旋转 loading 动画，隐藏原文字和装饰图标；不要改成“请求中”“提交中”“领取中”等文案，也不要将 spinner 与原文字并排显示。
- 按钮在默认、请求中、成功恢复、失败恢复四个状态下保持完全相同的宽高、边距和布局位置；相邻元素不能移动。不同语言下以各自默认按钮布局为准，不用统一写死所有按钮宽度。
- 实现时保留原文案的布局占位（例如隐藏但仍占位的标签），将 spinner 绝对定位到按钮中心，或使用等效的稳定布局。不能靠替换短文本、删除标签或加载时额外插入宽度来维持尺寸。
- Ant Design 的默认 `loading` 会保留文字并加入 spinner，直接使用不满足本规范；优先复用项目已有符合规范的公共组件，否则统一封装后使用，不逐页拼出不同效果。
- 从请求开始至接口成功或失败处理完毕，按钮不可重复触发；点击、键盘提交均需覆盖。存在最短展示时长时，必须同时满足接口结束和最短时长结束后才能恢复。
- 使用 `aria-busy` 标记加载状态；隐藏的文字不要丢失按钮的无障碍名称，spinner 作为装饰不重复朗读。禁止仅视觉禁用而仍能提交。
- 完成后按业务结果展示文案和可用状态，例如领取成功显示“已领取”并禁用；失败时通常恢复重试前文案。不要强制恢复原文案。成功、错误使用项目统一反馈，不自动重新提交支付、领取等业务。
- 修改后核对正常、慢响应、失败，以及中英文和320px窄屏；确认 spinner 持续旋转、文字不显示、按钮及相邻元素边界不变，并验证快速连点不会发出重复请求。

## 本项目公共组件

大厅已提供 `slots_lobby/src/components/buttons/AsyncButton.tsx`：原生按钮使用 `AsyncButton`，Ant Design 按钮使用 `AsyncAntButton`。传入 `loading` 和正常业务文案，不自己拼接请求中文案。覆盖范围见 `slots_lobby/docs/async-buttons.md`。

- 提交按钮的 loading 只对应本次点击发起的请求；后台查单、轮询或共享 Query 的 isFetching 不能反复触发提交按钮转圈，也不能把按钮改成“打开付款页面”等查单状态。请求结束后恢复正常按钮，后台确认独立运行。
