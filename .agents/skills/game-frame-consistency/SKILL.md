# 游戏帧与底部格子一致性（必须遵守）

- AG1、AG2、AG3 必须由服务端返回当前旋转对应的底部格子：`Frame.bottomSymbols`，使用服务端符号 ID，按列从左到右。AG1/AG2 为 5 个，AG3 为 6 个。
- 一次真正的新转轴旋转生成一组；同一旋转内连续消除、补落时底部不旋转，必须保持该组不变。不要把每次 spin HTTP 请求误解为一次新转轴旋转。
- 每个结算帧保存底部数据。spin、state.lastFrame、私人回放、公开回放、请求重试必须使用同一份已保存数据，不能在查询 state 或回放时重新采样。
- 顶部预览格已经在服务端 board 中返回，消除后参与补落；本规则只涉及底部，禁止用装饰格逻辑替代顶部预览数据。
- 底部是显示数据，不参与有效盘面验奖、派奖、RTP。不能改变有效格 ID、预览格数量或服务端 symbolId 到客户端美术的映射。
- 仅旧帧缺少 bottomSymbols 时允许沿用客户端随机；同一旋转消除时保留随机后的底部，禁止为了兼容旧数据回填或改写历史开奖结果。
- 有字段但列数或符号非法时应报告数据错误，不得静默随机掩盖问题。
- 验证至少覆盖：连续消除不变、新旋转有对应数据、存储/state/回放透传、客户端采用服务端值、旧帧兼容。构建对应客户端后才报告本地构建完成。
