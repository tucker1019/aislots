# 大厅接口失败状态

- 数据加载接口失败时，复用 `slots_lobby/src/components/feedback/NetworkError.tsx`，在所属内容区域居中显示“网络异常，请重试”，下面单独显示“重试”按钮。英文随当前语言显示对应翻译。
- 保留页面标题、返回和筛选；使用公共主题按钮、统一间距和响应式居中布局，不能使用裸默认按钮或各页各写失败文案。
- 点击重试只重新加载失败的数据；请求进行中显示 loading 并防止重复点击。不改变现有请求次数、退避和鉴权逻辑。
- 已有数据时保留内容，刷新/分页失败在相应区域使用同一公共错误组件，避免把现有记录清空或伪装成零金额、无数据。
- 余额不足、表单校验、订单已退回等业务状态保留明确业务提示。提交、支付、领取、取款等操作失败不得用通用重试自动重新发起业务操作，保留原幂等请求和结果确认流程。
- 修改后检查中英文、320px窄屏，以及失败后点击重试恢复成功的流程。
