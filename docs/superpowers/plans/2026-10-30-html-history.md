# 游戏区域内 HTML 下注记录与逐轮详情

已确认：History 打开覆盖游戏区域的HTML div，保留原Cocos场景；今天/最近7天/最多7天自定义筛选，底部统计整个筛选结果。列表徽标是中奖消除次数，详情轮数包含最终无奖盘面。详情为静态浏览，支持前后轮、普通/免费、盘面、倍率与可展开中奖计算，不做动画回放。

复用现有GameApi和登录token，不增加React或UI框架依赖，不重写游戏；TS DOM模块按数据/渲染/交互/样式拆分，使用现有真实牌面资源。关闭回到菜单，查询不开奖、不改变余额或请求标识。时间显示与日期范围统一GMT+8；金额使用BigInt和服务端整数/精确分数数据。
