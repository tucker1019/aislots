# 取款流水要求

已确认：启用后所有加币按来源独立配置倍数，默认1；0免要求。派彩、取款退回本金固定豁免。不追溯旧加币或旧投注，不预存超额流水。有效投注抵扣剩余要求；取款扣款前必须为0。

实施：
1. 增加严格JSON配置、来源校验及持久化规则快照。
2. 数据库新增启用时间、用户剩余要求、逐笔明细；资金流水插入与可信投注事件插入同步触发记账，复用钱包行锁，保持原事务和幂等性。
3. 协议增加本人剩余流水查询；取款创建在钱包锁内校验。已创建订单幂等重试仍返回原订单。
4. 取款页展示剩余有效流水，不满足时禁用新申请；未确认订单保持原请求号，不能被新门槛阻断结果恢复。
5. 隔离数据库验证：来源全覆盖、示例计算、0倍、固定豁免、旧数据、重启、配置快照、重复事件、并发和回滚。前端使用模拟接口验证，不执行实际取款。

取款期内领取新奖励后，不回溯取消已经创建的取款；新增要求限制后续新申请。规则变更只影响后续新加币。启用时间永久保存，不随重启移动。
