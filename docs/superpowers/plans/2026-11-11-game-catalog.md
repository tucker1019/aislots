# 后台游戏目录

沿用 games 配置分区及原有发布/回滚。每条游戏新增 cover、nameEn、sort、visible，enabled 表示上线。visible 缺省兼容旧配置为 true；新条目显式配置。未上线条目允许空入口地址。公开目录不包含入口、API 地址和平台密钥。

1. 扩展 GameEntry 校验；协议新增 GET /api/lobby/games，只返回显示条目，按 sort、ID 稳定排序。上线和展示状态同时限制新票据签发/兑换；历史结算保持可用。增加过滤、排序、敏感字段及启动门禁测试。
2. 迁入现有卡片顺序及图片到默认配置，AG1/AG2 上线，其他待上线。提供显式本地迁移，保留已发布开关和运营修改，使用草稿、审计和正常发布流程，不靠重启覆盖数据库。
3. 后台游戏编辑展示完整字段与中文说明，空条目使用模板；图片、顺序与开关可编辑，仍由操作者保存及发布。
4. 大厅独立 Query 读取目录，保留缓存和六行加载；无静态游戏列表回退，失败局部重试。名称、封面、厂商和上线状态来自目录，路由接受合法游戏 ID；详情先确认目录再加载缓存入口，防止下线游戏借缓存进入。
5. 运行协议生成、Go 测试及 lint，两个前端 lint/typecheck/test/build；验证本地目录接口、发布配置、进入游戏与未上线提示。仅更新本地，不发布远程。

- 本地 games 配置已通过显式迁移发布为 v3，共 81 项，仅两个已接入游戏上线；原有地址及运营开关保留。大厅服务、后台服务已重建并重启。
- 大厅 lint/typecheck/build 通过；61 个测试文件、175 项用例通过（`npm test -- --maxWorkers=2`，避免本机并发负载导致既有 UI 测试超时）。后台 lint/typecheck/build 通过，16 项用例通过。
- 大厅服务协议生成、`go test ./...`、`make lint` 通过。`make test` 的用例全部通过，但其覆盖率门槛被原有 `pkg/xerr` 61.5%（要求 90%）阻挡；未修改无关业务代码。目录逻辑覆盖率 100%。
- 浏览器验证目录首批 18 项、下滑追加 36 项、待上线提示及已上线游戏打开。HTTP 目录不含私有地址，待上线入口的直接 launch 请求被拒绝。
