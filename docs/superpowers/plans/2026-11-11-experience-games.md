# 体验账号固定游戏及停止策略

- 体验账号配置新增 gameWeights（游戏 ID → 非负整数权重）、stopEveryRounds（默认 50）、stopChancePercent（默认 20，0 关闭随机停止）。复用后台草稿/发布，不改变已发布启用状态。
- 缺失旧字段保留原单游戏及停止策略；后台显示可编辑默认值。只有上线、存在游戏 API 且权重大于 0 的游戏参与新账号分配。旧账号迁移绑定原游戏，新账号创建时保存 game_id，数据库禁止改绑。
- 调度按账号游戏调用对应的投注档位和整局接口。权重变更只影响新账号；绑定游戏下线后暂停新局，未完成请求保留原参数恢复。不切换游戏。单个游戏失败不跳过其他游戏任务。
- 游戏服自动整局接口解除单游戏限制，仍校验平台、游戏投注配置及幂等，隔离测试覆盖第二游戏完整免费局与重试。
- 后台体验账号页面显示游戏权重、上线状态及有效分配比例，停止参数直接编辑。生成数据库模型前先迁移本地大厅库；不启动原本关闭的服务、不修改真实用户或触发真实资金测试。
- 验证：确定性权重边界、上下线/0 权重、固定绑定及迁移、停止边界与 0/100% 概率、隔离数据库整局重试、后台 lint/typecheck/tests/build、两个服务 Go 测试及 lint。

## 实施结果

- 本地迁移新增固定 game_id，旧账号默认保留原游戏，模型通过 make model 从迁移后的大厅库生成。账号改绑会被数据库拒绝。
- 已完成权重表、可调停止间隔/概率、逐游戏投注策略及自动整局支持。后台 18 项测试、lint/typecheck/build 通过；大厅服和游戏服完整 go test 通过，大厅服 lint、游戏服 vet 通过。新增隔离数据库测试验证固定绑定、下线后的原请求恢复、不同游戏路由、按配置停止、新建权重及整局免费旋转的重试幂等。
- 本地大厅服、后台、游戏服已更新并重启。只读探测两个游戏 auto-bets 均返回 200。保留操作者已发布 v4 的启用状态及创建/游玩间隔；未自动发布新的权重或停止策略。旧文档没有权重时继续原单游戏逻辑，后台给新游戏设置正权重并发布后参与创建分配。
