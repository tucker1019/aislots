开局前的出口 建议

主动退出／房主取消／等人超时 → 退回赌注与未消费本金。开始和取消并发，只有一个事务能成功。

开局后的出口 已确认

关闭页面／网络断开 → 系统继续 Spin → 重连取当前快照。不能取消参赛或因离线判负。

系统异常：暂停 → 按原开奖结果与资金收据恢复。无法恢复进入人工审核，不自动重抽、不全退已消费本金。

重连路径

认证 → 房间快照／事件补发 → 当前对局

重新连接不代表重新加入，不再次扣款。历史动画可跳过；显示离线期间已完成局数。WebSocket只传递展示状态，不承担比赛调度。

恢复与审计

跨库重试原计划、事件补发、资金不变量核验、异常暂停

两个服务独立数据库：先存开奖结果计划 → 大厅幂等消费本金／入派彩 → 游戏提交同一帧。故障恢复不得重新开奖。

不重复扣

入桌事务唯一；每局只消费一次本金；帧派奖和奖池各有唯一业务键。

不重复算

付费链计一局，免费／消除不另计；奖池收入不计入成绩。

不遗留桌

关闭新桌入口后继续处理已扣款桌。上线回滚先排空存量。

开发前需要定下的规则

以下均为待评审事项；建议值还没有写入业务配置。

D013–4人并列最高

建议并列者平分奖池，固定顺序分余数；确认前不开放多人真实结算。

D02人数与开始

建议开桌选定2/3/4人，满员全员准备，由房主开始。

D03等待与取消

建议等人10分钟全退，房主开局前退出则取消；是否允许零赌注待定。

D04提现流水 真钱上线阻断

好友桌投注是否抵扣既有流水？游戏、奖池、专属奖励的资金限制分别如何处理？

D05不可恢复故障

暂停优先；建议审批后退未用本金及未分配赌注，保留已确认派彩。

D06专属奖励

条件、金额、精度、限次与防刷未定；初版不开启，不阻断核心桌设计。

D07游戏、局数与节奏

建议一款游戏先验证；确认N上限、Bet档位及完整免费链的展示节奏。

D08邀请与参赛限制

建议私密邀请码／链接，一人同时最多一桌，参赛期间禁止普通Spin。

实施顺序：规则 → 资金底座 → 可信游戏 → 持久调度／实时 → 交互 → 活动与报表 → 故障演练／灰度。无预设工期。
