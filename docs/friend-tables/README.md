## 已确认的核心规则

- 2–4 人，同款游戏、相同每局 Bet 和付费 Spin 局数，各自使用独立开奖结果。
- 对战赌注独立于游戏本金，每人赌注相同，且 `赌注 ≤ 每局实际投注 × 付费局数`。
- 确认开桌／入桌时，**一次事务扣除「赌注 + Bet × N」**；余额不足则全部不扣、入桌失败。
- 赌注进入奖池；预付本金仅供这桌 Spin 消耗，每局不能再次扣玩家可用余额。
- 比较 N 局内的总游戏派彩，获胜者取得奖池；正常游戏派彩仍归玩家本人。
- 开局后不可取消参赛；离开页面、断线不等于退赛，服务端继续完成全部 Spin。
- 双方实时看到对方的 Spin；不以对方页面是否在线作为推进条件。
- 好友桌不参加普通活动；未来专属奖励另设规则，当前条件／金额均未确定。
- 个人报表提供独立「好友桌」选项，与普通游戏分开查看。

## 评审重点

1. 先看 [需求文档中的待定事项](requirements.md#待定事项)，尤其多人并列第一、提现流水和异常中止。
2. 再看 [一次扣款与两类资金](requirements.md#资金模型与算例)，核对本金与奖池没有重复扣算。
3. 技术上必须先完成“预付本金结算”和“活动隔离”，才能接入真实好友桌 Spin；不能先把普通接口接到新页面上。
4. 建议以一款经过验证的游戏完成纵向闭环，再逐游戏开放；这只是实施建议，不限制最终游戏范围。

文中 **已确认** 来自本次对话；**建议** 是待评审的设计选择；**待定／阻断** 在确定前不得当成最终结算规则实现。交互图为结构示意，不是最终视觉稿。
