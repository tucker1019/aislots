# AG6 金鼠数值配置

在 `slot_math` 选择 AG6 并读取游戏文件，可编辑倍率权重、普通中奖率、特殊触发率，应用后查看理论结果或运行固定种子模拟，保存后写入本目录。开发页提供手动验奖、实时空奖、两种模式的骨架生成、覆盖检查、补空与特殊流程预览、候选库保存。

## 数值单位与流程

- `config.json`：规则标识 `fortune_mouse_v1`。固定五线；普通中奖率初始28%；特殊触发率初始1.4%；特殊整段中奖率固定100%。
- `base.json`：普通模式中奖后的原始总倍率与权重。312个Lua正倍率档，另有零权重5000档。空奖由普通中奖率控制，不重复保存零倍率。
- `free.json`：整段特殊功能最后一次中奖的原始总倍率与权重。267个Lua正倍率档，另有零权重5000档。不能解释为每次重转的独立奖金表。
- `paylines.json`：九格五线、七种图标、固定赔付、全盘百搭大奖、形态权重。位置按列从左到右、每列从上到下；配置线号为1～9，骨架位置为0～8。

一次投注先抽模式。普通模式再按普通中奖率决定正奖或零奖；特殊模式直接抽整段最终正奖。两种模式互斥。

```text
总返还率 = (1 − 特殊触发率) × 普通中奖率 × 普通表加权均值 ÷ 5
          + 特殊触发率 × 特殊表加权均值 ÷ 5
实际奖金 = 原始倍率 × 总投注 ÷ 5
```

初始总返还率约97.0253239%，普通贡献87.0253140%，特殊贡献10.0000099%，整笔投注中奖率29.008%。全盘百搭支付总投注1000倍，文件原始倍率为5000，替代线奖。该档初始权重为0，启用时需要在对应表显式调权并重新查看返还率。非全盘百搭的原始1000档保留。

特殊模式中列三格固定百搭，左右列每次清空重转。前段2～8个盘面必须为零奖，最后一个盘面支付选定倍率，支付一次后立即结束。长度策略见[规则说明](../../slot_math/docs/ag6-rules.md)。长度只影响展示，不改变最终奖金或返还率。

## 来源与可重现导入

采用Lua1019实际运行的 `room.lua` 普通和特殊表，完整原表、哈希、零奖权重及求和尾差保存在 `lua-1019-source.json`。普通中奖率按运行抽样范围10000000和零权重7200000分离为28%；正奖条件分布按原正权重归一化。生成脚本中的普通零权重7900000未使用。不引入外部调控、缺档降倍率或回退空奖。

导入器核对源码哈希，并拒绝覆盖已有输出目录：

```sh
node slot_math/tools/import-mouse-lua.mjs /path/to/1019/room.lua /path/to/new-output-directory
```

工具自行枚举和验奖生成新骨架，没有导入Lua开奖结果库。图标初始形态权重来自1019生成脚本，只影响合法盘面的形态和枚举顺序，不改变实际倍率概率。

## 骨架与实时补空契约

`mouse-skeleton-v1` 候选数据格式为原始倍率桶，单条只包含必要格子：

```json
{"3":[{"cells":[0,1,3,1,6,1]}]}
```

`cells` 为 `[零基位置, 图标编号, ...]`。普通骨架固定中奖格；特殊骨架另固定中列位置3、4、5的百搭7。全盘百搭固定九格。每条骨架的原始奖金精确等于桶键。特殊库只表示最后中奖盘面；前段空奖和展示帧不存入骨架。

实玩消费：先按数值参数抽模式、中奖和倍率，再选对应倍率桶内的骨架，实时补齐非中奖格。无奖盘面直接实时生成，不依赖零奖桶。不得用骨架数量估计开奖概率，缺档不得回退其他倍率或空奖。

补空按列从上到下，候选仅使用六种普通图标，先排除会新增中奖线的图标，再按形态权重抽一次。每个空位只消耗一次随机抽取，不重摇、不回溯、不替换骨架。最多四条线经过同一格，六种普通图标足以提供合法候选；两个固定百搭加一个空格的不可补形态在抽取前拒绝。补齐后重验原始奖金与逐线中奖信息不变。特殊零奖同样固定中列三个百搭。

生成器在工作线程分块枚举，固定种子确定形态顺序，优先枚举中列百搭盘面；普通模式随后枚举全部九格组合。全部目标覆盖后再尝试10万个盘面增加形态，或到次数、空间上限结束；每倍率和总容量均有上限，最多20000条、24 MiB。手动停止保留已完整处理结果。生成时包含5000展示桶，即使其权重为0；覆盖要求只看当前表的正权重正倍率，缺失明确报告。

配置保存与骨架保存相互独立。骨架保存检查数值和盘面两个版本，并逐条重验；写入 `game_libraries/AG6/<base|free>/<新批次>/library.json` 和 `manifest.json`。清单含配置、倍率表、参数、种子、统计、版本、哈希和覆盖。只创建候选，不自动启用、不覆盖旧批次。调整数值后须重新生成相应候选。
