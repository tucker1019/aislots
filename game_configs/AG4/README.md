# AG4 连线初始配置

客户端只读来源：fortunetiger_1017/assets/fortunetiger/src/game/FTConstant/FTConstant.ts（PRAFAB_LIST / WILD_TYPE / ALL_LINE）。

- 1 橘子 3、2 鞭炮 5、3 红包 8、4 福袋 10、5 如意 25、6 金元宝 100、7 Wild 250；0 空白。
- paylines.json 为连线工具的配置源。位置编号按列从左向右、每列自上向下从 1 开始；该编号不是客户端符号 ID，也不代表客户端网络盘面索引。
- 3×3 五组：中横、上横、下横、两条对角线。每组全部位置匹配同一符号（Wild 可替代），只取最高赔率。
- 奖金 = 总投注 / 中奖组合总数 × 各中奖组赔率之和。
- 等权重仅供测试，未调 RTP。不实现 AG4 重转、全盘 ×10；未接游戏服务端、未生成或发布盘面库。
- base/free JSON 为兼容现有文件工作区所需的未启用占位表，分析页对 paylines_v1 禁用旧消除模型；它们不参与连线验奖。未来倍率模型接入时替换，不可作为上线配置。
