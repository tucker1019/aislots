# AG7 金牛

`base.json`、`free.json` 直接控制普通正奖及特殊整段最终奖的倍率分布。`config.json` 初始采用1023运行参数：普通中奖率29%、特殊触发率0.7%、特殊整段必中奖。`paylines.json` 保存3、4、3格盘面、十条线和固定赔付，图标权重只控制形态。

普通77个、特殊26个正权重档全部保留；普通表额外有零权重原始20000档，对应确认后的全盘纯百搭总投注2000倍，初始开奖概率不变。特殊左右六格为同一种普通图标，不允许纯百搭满盘。完整来源表、源码哈希、旧次数表与实际采样区间保存在 `lua-1023-source.json`。

初始理论返还率约97.003563%。满盘普通图标混百搭统一按该普通图标计算，十倍已计入骨架桶键，不再重复乘。

骨架由数值开发页生成在 `game_libraries/AG7`，空奖由后端实时生成。规则与数值口径见[规则说明](../../slot_math/docs/ag7-rules.md)，Go 模块见[服务端说明](../../slots_service/internal/games/ag7/README.md)。
