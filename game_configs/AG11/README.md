# AG11（Lua 1026）

AG11 使用 6×5 盘面，共 30 格。九种普通图标全盘计数，达到 8 个起奖，12 个及以上按 12 个档支付；中奖图标消除后下落、补入并继续结算。散射图标 4 个支付 3 倍、5 个支付 5 倍、6 个及以上支付 100 倍。倍率图标面值权重分普通局和免费局两张表。

`base.json`、`free.json` 与购买免费结果表从 Lua 1026 导入。1.25 倍投注的独立 `rates_base_double`、`rates_free_double` 保存在 `config.json.parameters.bet125`，实际扣款按基础投注的 1.25 倍计算，Lua freeMode=2 的免费触发率为 0.66666%。`base.json` 只保留 459 个正倍率档，普通空奖由 `config.json.parameters.baseSpinWinProbability` 控制；`free.json` 表示自然触发后整个免费阶段的完整结果，包含触发盘面、初始 15 次免费及可能的追加；`config.json.parameters.purchaseFreeWeights` 是 100 倍投注购买免费时的独立整段结果分布。骨架数不参与概率计算。

按当前配置，普通中奖率为 29%，普通正倍率表均值为 2.98127362，免费整段表均值为 32.97097155，触发率以 `config.json` 为准；理论自然 RTP 按这三个参数计算。购买表均值为 97.00562520，成本为 100 倍，购买免费 RTP 为 97.0056%。自然投注、1.25 倍投注和 100 倍购买免费三种 RTP 分别展示，不混在自然投注 RTP 中。1.25 倍模式的普通表均值为 3.36779138、免费表均值为 36.37606891，按 1.25 倍实际扣款换算后的理论 RTP 约为 97.0123%。

免费骨架必须保存触发盘面和完整免费序列。每局记录连消盘面、本局连消倍率、本局新增倍率、累计倍率、追加次数和本局结算倍率；累计值只加本局新出现的倍率，例如 `2 → 5 → 15`。空奖由服务端实时生成；固定骨架补空只执行一次，重验不得增加中奖或改变选定倍率。

规则来源：`/Users/zhaoyao/game_lua/game/service/qd/1026/room.lua`、`1026.lua` 与 `game/conf/slotCfg_1026.lua`。`lua-1026-source.json` 记录权重表规模和语义。`board.json` 保存赔付、倍率图标权重及两套 1000 格转轴。

开发页读取 `paylines.json` 作为 AG11 盘面快照。可手动验奖、实时生成空奖、按普通/免费倍率表与 1.25 倍表的正权重并集生成候选中奖骨架，并显示缺失倍率；候选库保存为独立批次，不改变权重和 RTP。

`paylines.json` 的 `generationWeights.base/free` 是开发页的图标元素生成权重，分别对应普通盘面和免费盘面。它们只影响中奖骨架形态、补空候选和生成效率，不参与倍率开奖权重或 RTP。
