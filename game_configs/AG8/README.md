# AG8 数值输入

先在数值工具选择AG8，读取游戏文件。普通、五倍投注可分别调整概率和倍率表；应用后更新理论及模拟，保存后写入文件。四表和全部概率、底部倍率权重一次保存，外部文件变化时拒绝覆盖并保留页面草稿。

| 文件 | 用途 |
| --- | --- |
| `base.json` | 普通投注的普通转正奖原始倍率、权重 |
| `free.json` | 普通投注的单次免费转正奖原始倍率、权重 |
| `config.json` | 中奖率、触发率、8次免费、2500倍上限、底部倍率及五倍模式两表 |
| `paylines.json` | 三列三行、五线、固定赔付及可调图标形态权重 |
| `lua-1048-source.json` | 初始Lua数据与源码哈希，仅供来源核对 |

所有表倍率均未乘底部倍率。普通投注以5为除数，五倍投注以25为除数换算为实际扣款倍率。空奖由中奖率控制，不在表中保存零倍率。免费倍率数量和单个倍率分别抽取、倍率相加，不累计符号。

初始导入四张各194档的旧Lua表。普通模式中奖率约22%/28%，五倍模式100%/100%，触发率0.66%。理论返还率分别约97.0019028%和97.0012512%。保留Lua浮点权重求和所对应的原始精度，底部权重按实际总和归一化。

初始导入命令在 `slot_math` 下运行：

```sh
node tools/import-dragon-lua.mjs /path/to/slotCfg_1048.lua /全新目录/AG8
```

导入器核对已确认源码哈希，拒绝覆盖任何已有目录。后续调参不重复导入；导入时不读取Lua结果库或外部调控器。

开发页保存形态参数后生成普通和免费中奖库，每个库覆盖普通、五倍模式对应表的正权重倍率并集。当前各580条、覆盖194/194，见 `game_libraries/AG8/`。空奖与非中奖格由后端一次实时构造，无零奖库。候选不会自动启用；Go使用独立验证后的发布快照。

同一生成器也可由工具调用，第二参数为数值工具地址，第三参数可选 `base` 或 `free`；不传第三参数时生成两库：

```sh
node tools/generate-dragon-candidates.mjs http://127.0.0.1:5196
```

完整规则及奖金模型见[AG8规则](../../slot_math/docs/ag8-rules.md)。
