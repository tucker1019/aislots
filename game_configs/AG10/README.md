# AG10 数值配置

AG10 采用 Lua 1022 的金兔盘面和数值表，按 AG5 的数值工具与服务端流程实现。截图中的赔付数字不作为 AG10 数值来源。

- `base.json`：Lua 1022 的普通中奖原始倍率及权重，零奖移入普通中奖率。
- `free.json`：按 Lua 1022 奖励面值权重推导的单次特殊转中奖原始倍率分布。
- `config.json`：十线、普通中奖率 29%、当前特殊单转中奖率 34%、特殊触发率 0.6%、八次特殊转、整局 5000 倍封顶。Lua 1022 推导出的原始特殊中奖率约为 36.68967424%，当前配置按数值调整为 34%。
- `paylines.json`：三列 3、4、3 格、十条线；普通图标赔付为 2、3、5、10、50、100，百搭为 200。
- `lua-1022-source.json`：Lua 来源哈希和推导口径。

原始倍率除以十得到总投注倍数。特殊奖励值 5000（总投注 500 倍）在 Lua 1022 中没有正权重，保留为规则上限但初始不抽取。普通、特殊中奖骨架分别生成；空奖由服务端实时构造，补空不得新增中奖。
