# AISlots 游戏大厅

独立 React + TypeScript 前端，位于仓库根目录 `slots_lobby/`。使用 Ant Design、TanStack Query、Zustand。

## 运行

需要 Node.js >= 22.12，推荐使用仓库当前的 Node 22.22.2。

```sh
cd slots_lobby
npm ci
npm run dev
```

打开 http://127.0.0.1:5175/ 。构建预览运行 `npm run build`、`npm run preview`（4175端口）。

## 页面适配

大厅最大宽度430px，电脑上居中、两侧留灰底，手机上铺满可用宽度，不使用整页缩放。顶栏下依次为通知、Banner、厂商分类、三列游戏网格；当前只有麻将胡了一款游戏。首页保留厂商分类和游戏网格，底部导航提供大厅、存款、赚钱和我的等页面入口；游戏页和部分详情页按需隐藏导航。

顶栏固定在顶部并预留等高内容空间，右侧显示真实金币与头像，兼容顶部安全区。

厂商入口只有“热门、AG、PG、JILI、PP”。热门和AG显示麻将游戏；其他厂商点击Toast“敬请期待”，保持当前分类与列表。通知及Banner目前为本地内容，通知在`src/features/home/content.ts`修改，Banner/封面资源位于`public/assets/lobby`，复制自现有麻将客户端。AG1入口已接入大厅票据登录和统一钱包，详情见下文。

## 大厅用户服务

先在另一个终端启动独立大厅服务（不替换8080端口的麻将服务）：

```sh
cd ../lobby_service
docker compose up -d
export LOBBY_DATABASE_URL='postgres://lobby:lobby-local-only@127.0.0.1:55433/aislots_lobby?sslmode=disable'
make run
```

开发和构建预览将 `/api/user`、`/api/game`、`/api/recharge`、`/api/activity`、`/api/vip` 代理到本机8081端口。正式部署需要同源反向代理，或者通过 `VITE_LOBBY_API_URL` 设置允许跨域的大厅接口源站；该变量不附加 `/api` 路径。

首次进入创建游客，本机身份保存后刷新先续期，再获取资料。会话失效保留原身份并提示错误，后续账号登录界面另做。Query持有资料及余额，窗口重新获得焦点且缓存过期时刷新；Zustand只持久化uid/sid/到期时间，密码和余额不落本机缓存。网络请求12秒超时，失败显示重试，不用0冒充失败结果。并发挂载共用一次登录，请求失败不自动重放创建游客。

余额为整数分，显示两位小数；服务端头像编号1–15对应 `public/assets/profile/avatar` 的同名图片，资源复制自用户指定的AB3目录。失败/加载时用中性占位头像。

## 目录

- `src/app`：应用入口、主题和Query Provider。
- `src/pages`：大厅页面组合和Toast，不直接请求接口。
- `src/components`：固定顶栏、品牌和金币图标。
- `src/features/account`：余额、头像及加载/错误/重试状态。
- `src/features/home`：通知、Banner、厂商选择及游戏卡片。
- `src/services/account.ts`：登录、续期、资料请求与响应校验。
- `src/stores/session.ts`：持久化身份，不缓存余额。
- `src/styles`：全局适配与顶栏样式。

大厅身份和钱包已通过票据及服务端结算与麻将服务互通；现有账户、充值、福利、VIP、赚钱、邀请及记录页面。配置示例见`.env.example`。

## 路由

首页路径`/`，我的路径`/my`。使用History API，支持直接访问、刷新保留和浏览器前进后退；我的页隐藏顶栏并移除顶部占位，仅保留固定底栏。正式静态部署需将`/my`等前端路径回退到`index.html`，API路径继续走服务端代理。

## 存款页

`/deposit`由底栏存款和我的页存款进入；无大厅顶栏。查询充值档位，展示本金、赠送、手续费及到账金额。创建订单使用requestId幂等；不确定失败时重试同一请求号，不允许换档位；sessionStorage按UID保存本次意图及订单号，刷新可恢复订单查询。待确认订单每秒查询，成功/失败停止；查询失败显示手动刷新。成功后重新读取当前余额，不用历史订单余额覆盖资料。

当前后端为测试支付，页面明确提示约3秒自动模拟到账，不需要真实支付。付款链接仅接受HTTP(S)且禁止内嵌身份。开发/预览代理`/api/recharge`至8081，正式部署也需配置代理。自动测试使用模拟接口，不执行真实充值。

## AG1真实游戏入口

麻将卡片点击后，使用当前大厅uid/sid请求 `POST /api/game/launch`，等待服务器返回临时launchUrl后，在大厅/game/AG1游戏页通过iframe加载；不再直接打开固定测试客户端地址。进入按钮加载期间禁用，失败提示并可重试。开发代理已包含 `/api/game`。后端及共享服务凭据配置见 [AG1接入文档](../lobby_service/docs/game-integration.md)。

游戏页提供返回大厅和重新进入，隐藏大厅顶栏及底部导航；刷新保留当前iframe入口，已兑换票据复用游戏会话，不重复兑换。返回大厅重新获取钱包余额。

## 存取记录

“我的 → 存取记录”读取当前用户真实存取款订单，支持全部/存款/取款，以及今天、昨天、近7天、近30天筛选。时间由服务端过滤，列表分页追加，点击行进入可刷新的订单详情并复制订单号。详情返回保留列表筛选、分页和滚动位置，离开页面刷新钱包缓存。失败或未确认订单不会伪装为已到账。

页面切换和筛选浮层使用轻量过渡，并尊重系统减少动态效果设置。

VIP查看详情：福利中心“VIP中心→查看详情”进入 `/vip`，按真实等级显示升级差额、等级权益与保级状态；可横向选择其他等级查看权益。右上角“VIP详情”进入 `/vip/details`，展示晋级/保级、礼金和周期条件三张完整配置表，高亮当前等级。数据来自 `/api/vip/info`，金额由分换算为元，升级礼金、周工资及月工资按服务端资格手动领取，领取后刷新余额及相关数据。

个人报表：我的→个人报表，独立路由`/personal-report`。复用RecordsLayout固定标题与今天/昨天/本周/上周筛选；统计周期由服务端按活动时区计算，各项奖励独立展示，未实现项目为`—`。报表在进入页面、切换日期或切回窗口时刷新，不做定时刷新，余额本金不混入净输赢。

## 多语言

我的页面底部提供语言选择，支持繁体中文、英文和印尼语，使用本机`aislots-language`保存选择，默认繁体中文。语言切换即时更新大厅、Ant Design组件、数字/日期格式，不刷新页面，不改变用户名、交易ID或路由。游戏iframe内部的语言由游戏客户端自身负责。

界面文案统一放在`src/i18n/locales/zh-TW.json`、`en-US.json`和`id-ID.json`，通过类型安全的`t(key, params)`读取。`src/i18n/config.ts`集中注册语言、语言名称和Ant Design locale；新增语言时补齐同结构JSON及注册项。不得用翻译后的文案作路由、接口字段或业务ID。语言支持繁体中文（zh-TW）、英文（en-US）与印尼语（id-ID），旧简体语言偏好自动迁移。服务端报表与账变按稳定英文业务ID映射翻译，禁止中文key或中文文案反查，用户输入不参与翻译。`npm run check:i18n`检查新增内联中文文案，build默认执行；测试同时核对语言key及插值参数一致。

邀请好友：我的→邀请好友，路由`/invite`。规则、阶梯单价、邀请链接、客服地址和统计均读取服务端；客服图标打开Telegram，不展示下载APP或收款资料入口。首次创建游客时提交URL中的inviteCode，失败可重试，身份创建成功后清除邀请参数；已有身份忽略并清除邀请码。手动领取邀请奖励后刷新余额与个人报表并显示统一领取成功Toast。

## 赚钱、邀请宝箱与好友详情

`/earn`展示反水、亏损返还及邀请宝箱，`/earn/rules`展示反水规则与预估；日周月金额分别展示，反水合领，亏损返还单独领取。`/invite/friends`分页展示直属好友在活动期限内的充值和投注进度。宝箱支持单独领取；接口权限和资格由服务端决定，不用前端统计发奖。

## 游戏统计与排行榜回放

游戏详情展示服务端RTP和派彩、倍数、连胜榜，支持配置的时间窗口。派彩和倍数榜订单可申请回放，在弹窗iframe中只读播放；连胜榜不提供回放。请求失败显示重试或不可用提示，不模拟统计结果。统计和回放口径见[服务端文档](../lobby_service/docs/game-statistics.md)。

中英文统计表使用共享行高，窄屏允许表内横向滚动。修改后应检查320px、中英文长文案和大金额的实际布局，不能仅依赖DOM测试。

## 代理中心

“我的→代理中心”进入`/agent`，支持今日返佣预估、佣金合领、团队逐层查询、分厂商业绩、代理报表、返佣比例、代理说明与领取记录。页面状态保存在查询参数，支持刷新及前进后退。保留邀请链接复制，不提供分享渠道或防封链接；当前仅AG，取款暂未开放。开发/预览将`/api/agent`代理至8081。

## 取款

“我的→取款”进入 `/withdrawal`，绑定取款账号后选择档位并提交；订单详情支持刷新恢复。开发环境启用服务端 `LOBBY_WITHDRAWAL_TEST_MODE=true` 后展示测试通过、测试退回按钮。提交异常保留原requestId重试；通过直接发放赠送，退回返还本金。规则见 `lobby_service/docs/withdrawal.md`，充值档位保持不变。

取款页通过 `/api/user/withdrawal/turnover` 展示待完成有效流水，未满足时禁止新申请。查询异常不能显示为0，使用公共错误/重试组件；已有未确认订单继续沿用原请求号确认。倍数由大厅 etc/turnover.json 按来源配置，派彩和取款退回本金豁免，历史不追溯。

印尼语显示名称为 Bahasa Indonesia。缺少印尼语版本的运营公告和活动图片使用英文版本，默认欢迎语及已知宣传替代文字使用印尼语；未知运营文案保留原文。语言选择不改变账号国家、币种或金额单位。
