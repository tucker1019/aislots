# 印尼市场大厅 · 第二版

预览：<http://127.0.0.1:4178/design-assets/lobby-indonesia-v2/>。由 `slots_lobby` 目录的本地 HTTP 静态服务器提供，默认端口 4178。第一版保留在相邻的 `lobby-redesign/`，两版互不覆盖。

本稿用中文评审。金额仍用 `Rp` 和印尼千位分隔，不修改服务端整数分协议；正式应用保留印尼语默认及三语支持。所有余额、订单、奖励、进度和榜单均为明确标注的设计示例，不调用业务接口。

## 主题

| 用途 | 色值 | 规则 |
| --- | --- | --- |
| 画布 | `#17152A` | 深靛紫承托游戏图片 |
| 面板 | `#252039` | 比画布亮一级，不给每张卡加光晕 |
| 次级面板 | `#342D4B` | 取款、详情等次操作 |
| 主操作 | `#FF9179` | 存款、领取、当前筛选；配 `#251624` 深色文字 |
| 辅助强调 | `#F4D49A` | VIP、进度、福利图标；不与主按钮争抢 |
| 正文 | `#FFF6ED` | 暖白，金额和标题共用 |
| 辅助文字 | `#C0B9D0` | 说明与周期，避免使用低透明度小字 |

这里的“面向印尼市场”落实在本地货币、默认语言、入口名称和资金／奖励信息上，不把“印尼玩家喜欢某种颜色”当成未经验证的结论。主按钮明确写“存款”，不只用加号；首页继续保留真实机台、厂商分类和三列封面。未添加现有系统不支持的 QRIS、银行或电子钱包渠道。

## 封面

`covers/AG1.webp` 至 `covers/AG10.webp` 是对仓库现有游戏素材的确定性裁切与合成：保留角色／麻将主体，去除原封面底部标题区域，将底板渐变到靛紫，在 HTML 中放中文标题。没有改游戏场景或角色动画，也没有将旧图简单染色。

页面提供“重排封面／原始封面”切换。`games.json` 保留原图路径及游戏 ID，正式目录接口不受影响；十款游戏只是布局样本，不假定它们在运营目录中全部可见。

本会话没有可调用的图片生成工具，本版没有冒充全新绘制。若后续选择生成新插画，应保留对应机台的角色识别，逐张审核，不将一套动物图错误复用到另一款游戏。

## 页面与交互

沿用第一版已梳理的业务范围：完整展示首页、存款、赚钱、我的、福利、VIP、资金／投注记录和游戏外壳。取款、代理、邀请、报表、安全等仍是范围说明页，不算完整页面交付。

- 存款单独展示本金、赠送、手续费、到账。正式金额和资格以服务端档位为准。
- 反水列出日／周／月的来源周期与金额，并支持一次领完；亏损返还单独领取。下一期预估与可领金额分区。
- 签到显示当前天、充值及投注进度；VIP 的升级和保级逻辑继续按既定业务规则，不因主题改版变化。
- 游戏 iframe、动画、回放与收起恢复沿用现有实现，本原型不替换 Cocos 画面。

正式实施还需保留公共 777 loading、封面骨架流光、按钮防重复和公共 Toast；本稿只验证视觉结构及可点击路径，不宣称已经覆盖正式 API 的慢请求／失败流程。`DESIGN.md` 和运行中的正式页面未修改，待方案确认后按页面落地。
