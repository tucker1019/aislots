# AISlots 大厅设计系统

参考：https://getdesign.md/apple/design-md （2026-11-02）。采用其克制的产品展示方式，不使用 Apple 商标。

- 页面白 #ffffff，浅灰 #f5f5f7，文字 #1d1d1f，次级 #6e6e73，交互蓝 #0066cc，焦点蓝 #0071e3，细线 #e5e5e8。
- 精选麻将区用淡青底 #eaf1eb 和真实牌面美术；游戏卡可使用与主题相关的底色，交互颜色保持蓝色。
- 字体：-apple-system / BlinkMacSystemFont / Segoe UI / 中文系统字体；不下载或伪造 SF Pro。
- 标题 56/40/32px，正文 17/15px，元数据 12/13px。全局统一标题和弹窗规格。
- 8px 基础间距；大厅最大430px，宽屏水平居中、两侧灰底，窄屏铺满。所有屏幕沿用手机竖版结构和两列游戏，不再切换桌面布局。
- 大厅高度100dvh，内部纵向滚动；底部导航和弹窗遮罩均限制在大厅宽度内，兼容底部安全区。窄于360px时按容器宽度微调文字。
- 英雄区域只有一个视觉焦点：复用麻将牌面的立体组合。标题与左侧正文对齐。
- 蓝色胶囊按钮代表主操作；卡片圆角18px，工具控件8/12px，收藏图标44px点击区域。
- 阴影仅用于表现牌面/游戏插画体积；卡片依靠底色区分，不堆叠浮雕阴影。
- 页面主体不使用装饰渐变；动效只反馈交互，并尊重 prefers-reduced-motion。
- 可玩、筹备、无搜索结果、收藏空态、服务错误、加载状态都要明确，禁止虚构在线人数、奖金或游戏可用性。
- 顶栏固定在大厅顶部，高度62px加顶部安全区，正文预留同高间距；右侧是金币与38px圆形头像。金币使用服务端余额，不用默认0覆盖错误状态。
