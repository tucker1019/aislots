# AISlots 大厅设计规范

当前深色主题采用用户确认的「印尼市场第二版」：深靛紫画布与面板、珊瑚橙主操作、暖金权益图标、暖白正文。保留现有业务；游戏详情页采用左封面、右标题的头部，标题和厂商下方用两列两行展示四项指标，兼容印尼语长文案，预览与操作区一体展示，榜单突出昵称和中奖金额；游戏 iframe、排行榜筛选、回放、分享、收起展开等功能沿用正式版，不使用预览中的简化外壳。

- 主题模式沿用当前实现（暂时固定深色，主题入口隐藏）；浅色基础变量保留。本次视觉修改不改变主题切换策略。
- 画布 `#17152A`，面板 `#252039`，顶栏与底栏 `#211C33`，次级容器 `#342D4B`，分隔线 `#4A405E`。正文 `#FFF6ED`，次要文字 `#C0B9D0`。
- 主操作与选中分类使用珊瑚橙 `#FF9179` 配深色文字 `#251624`；悬停 `#FFA58F`，按下 `#ED7C65`。VIP、福利图标用暖金 `#F4D49A`。金额使用正文色，导航当前项用珊瑚橙图标和短指示条。取消、退出等次要操作使用次级靛紫底，不将所有按钮都强调为主色。成功、错误和处理中保留语义颜色与文字提示。
- 全站可编辑文字统一使用本地圆体：Nunito 可变字体负责英文、印尼文和数字，粉圓体 Huninn 负责繁体中文，涵盖正文、标题、表单、按钮、金额及 Ant Design 弹层。Noto Sans TC 与系统字体只作缺字回退。正文 400，重点操作和区块标题 700，主标题、余额和到账等关键数字 800；Nunito 使用实际可变字重，Huninn 原字体仅有 400，重点文字允许浏览器合成粗体。金额保留等宽数字设置。首页控件圆角 12px、游戏卡片 14px；移除厚重实心底座、发光描边和装饰性文字投影。通过色面与留白组织层次，按钮状态切换保持尺寸和位置稳定。
- 保留 420px 大厅设计坐标、固定导航和安全区。首页的通知、Banner、厂商入口和三列游戏网格沿用现有数据；封面、头像和游戏 iframe 不重染色。
- 充值、取款、钱包及记录的余额、手续费、实际到账和状态优先清晰可读。保留原业务流程、档位和金额格式；未返回的数据使用局部加载或公共重试，不能伪造余额。加载中的按钮尺寸稳定。
- 大厅面向印尼市场，金额统一使用 `Rp` 前缀、印尼千位分隔且不显示小数，例如 `Rp18.030`，不随界面语言改变。展示时向零截去小数，不四舍五入。接口仍使用整数分，不能因展示格式改变记账、计算或提交金额。余额、奖励、记录与排行榜复用公共金额格式化，避免重复币种前缀；RTP、中奖倍数和费率保留必要小数。
- 未保存语言选择或保存值无效时，默认印尼语；保留已选择的繁体中文、英文或印尼语，旧简体中文偏好继续迁移为繁体中文。
- 金额不得使用省略号截断或缩小字号掩盖空间不足。余额容器按数字长度占宽，标题或操作区空间不足时允许换行；刷新三点动画继续保留原金额占位，刷新完成后才按新金额调整宽度。
- 同一套主题用于页面、弹窗、下拉和消息。繁体中文、英文、印尼语长文案、320px 窄屏、键盘焦点及减少动画偏好一并检查。

- 首页左右留白 20px，三列游戏网格列间距 10px、行间距 14px，原封面保持原比例，第二版重排封面使用 4:5。固定顶栏沿用紧凑单行排版：品牌、余额与小尺寸充值按钮、头像；余额与充值组合在同一容器，长金额允许在余额容器内换行并保留完整 title，不省略金额。所有页面共用顶栏高度变量。
- 「我的」钱包卡片使用靛紫面板，金额独占一行，存取款双列放在下方；福利使用五列图标网格，账户服务使用四列图标网格，所有原有入口保持可达。存款使用珊瑚橙、取款使用次级靛紫底。
- 深色模式下，禁用的实体按钮使用独立灰底、较亮的边线和浅灰文字，不只降低整体透明度；可用主按钮使用珊瑚橙配深色文字。加载沿用同一按钮占位和居中转圈。
- 首页分类及存取款档位选中时，用底色与文字颜色区分，不添加亮色描边或内描边阴影。保留原有占位尺寸；键盘焦点提示与选中状态分别处理。

- 新版封面位于 `public/assets/lobby/covers/indonesia-v2/`，由已授权的现有素材裁切合成，标题取实时目录和当前语言。只替换匹配原始内置封面的 AG1–AG10；后台自定义封面保持权威，新图加载失败回退原图。不得据此写死游戏数量、排序或可见性。运营 Banner 和 Cocos 游戏内资源不变。
- 首页增加签到、VIP、反水轻量入口；继续保留厂商筛选和封面流光。赚钱页沿用原有结构：邀请宝箱、代理佣金、反水、亏损返还；预估金额保留横向表格，不新增结算明细表。领取仍使用既有接口。
- 设计稿中文仅供评审，正式页面继续使用语义多语言 key 和印尼语默认。全局变量在 `styles/theme.css`，Ant Design token 在 `app/theme.ts`，第二版组件布局在 `styles/indonesia.css`，避免逐页硬编码颜色。

- 游戏详情右上角提供收藏和分享，使用低强调图标按钮；收藏成功后星标变暖金色，不与“放大并游戏”的珊瑚色主按钮竞争。收藏由大厅服务按账号持久化，大厅分类顺序为热门、收藏、厂商，横向排列。收藏不恢复后台隐藏的游戏。
- 分享链接使用 `/game/{gameId}`，不携带 sid、launchTicket 或 iframe 地址。有效游戏深链允许登录后进入；其他外部子页继续执行首页入口限制。

- 存款与取款金额档位选中态使用柔和紫色 `#66517f` 配暖白金额 `#fff6ed`，手续费角标保持原有样式；珊瑚橙继续用于提交等主操作。

- 首页近期大奖位于 Banner 与厂商分类之间，移除该位置的签到/VIP/反水快捷栏。大奖游戏小封面横排、脱敏昵称旁放小验证盾牌，游戏图上覆盖半透明回放标识；倍数置于封面底部的淡色半透明深底板，居中显示；不显示订单号和验证文字。自己的记录显示“你”与轻微底色。整张卡片打开居中投注详情弹窗，卡片金额前显示 WIN。仅此区金额超过三位时使用 k 并向零保留一位小数，其余页面保持完整 Rp 金额。初次加载或请求失败使用卡片高度的动画骨架，自动最多请求5次；耗尽后继续保留骨架，离开首页停止请求。详细协议和统计见 ../lobby_service/docs/recent-wins.md。

- 近期大奖为只读的连续自动滚动，每屏四个游戏，不支持手动滑动或左右切换。刷新结果单独缓存，不追加到当前批次；当前批次结束直接接最新批次（如旧49、旧50、新1、新2，接着新3、新4），无新数据时首尾循环，不重置整行位置。

- 近期大奖卡片的半透明大回放标识覆盖游戏图，金额前显示 WIN；整张卡片只有一个点击入口，打开居中投注详情 Modal。卡片内图片和回放标识不单独跳转或请求；详情内提供回放、分享和进入对应游戏。详情使用真实投注额、订单号、头像与时间。
