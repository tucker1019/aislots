# AISlots 当前界面约定

- 保留手机竖版容器，最大430px；电脑居中、外侧灰底，手机铺满。
- 顶栏固定在顶部，高62px加顶部安全区，正文预留同等高度。
- 顶栏保留AISlots品牌，右侧为真实金币余额和38px圆形头像。
- 页面白色，主文字#1d1d1f，次级#6e6e73，交互蓝#0066cc，外侧#e9eaee。
- 字体沿用用户确认的系统字体栈，无外部字体依赖。
- 顶栏下依次为紧凑通知、横幅Banner、热门/AG/PG/JILI/PP五个厂商入口、三列游戏网格。仅一张麻将卡片，保持一列卡片宽度，不补假游戏。
- 热门/AG可选，其他厂商点击提示“敬请期待”并保持当前列表；Toast对齐大厅中心，限定在容器宽度内。
- 通知先用欢迎文案，Banner和封面复用麻将客户端资源；后续可替换正式素材，不展示未确认的活动奖励。
- 余额和头像来自大厅服务端；加载/失败状态不展示伪造金额。
- 动效遵循prefers-reduced-motion。

## 主题

- 大厅支持浅色和深色手动切换，入口位于“我的 → 主题”，使用本地 `aislots-theme` 保存选择，默认为浅色。
- 深色使用蓝黑页面、分层卡片、浅色文字和蓝色交互色；游戏 iframe、海报、头像保持原资源，不使用全页滤镜反色。
- 原生 CSS 的背景、文字、边框通过 `src/styles/theme.css` 的语义变量切换，`var(--theme-*,原浅色值)` 保持浅色效果兼容；Ant Design 通过 `app/theme.ts` 统一算法及令牌切换。新增界面复用这些变量，避免固定白底或深色文字造成主题不一致。
- 主按钮白字配较深蓝底，链接使用浅蓝；同时检查中英文、320px及弹窗、表格、输入框，不改变已有布局尺寸。
