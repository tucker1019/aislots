# 可领取奖励红点

红点文案为“領”（英文 Claim），绝对定位在入口或按钮右上角，呼吸动画不改变布局；减少动态效果的系统设置下停止动画。

- 赚钱：邀请宝箱、游戏返水、亏损返还、代理佣金。
- 我的：签到、周礼金、月礼金、晋级奖励及代理中心；VIP入口汇总周、月和晋级奖励。
- 邀请好友介绍页没有领取操作，宝箱领取提示显示在赚钱页。
- 只显示服务端已经可以领取且金额大于零的项目，不将预估金额视为可领取。

`ClaimIndicatorsSync` 在已登录时读取各业务的现有接口；`useClaimIndicators` 只观察共享 Query 缓存，不自行请求。按 UID 隔离，未登录不显示。登录时读取一次，领取成功只更新对应奖励；从游戏退出回大厅时刷新一次领取资格，因为投注可能改变流水。普通底栏切换、充值到账均不刷新领奖接口，不添加定时轮询。

领取 mutation 用 `claimIndicator` 和 `claimUid` 元数据声明所属奖励，VIP礼金还可声明 `rewardKind`。公共 MutationCache 在请求开始时记录所属账号，成功后先移除本次已领取项，再刷新对应服务端状态；失败不消除。VIP多笔晋级奖励和邀请宝箱逐项扣减，不清空其他可领取项目。异步请求期间切换账号，旧请求不能修改新账号红点。

新增可领取业务时，需要补充奖励源、聚合入口和领取 mutation 元数据，并覆盖子入口消失、父入口保留及账号切换测试。
