使用 `components/buttons/AsyncButton.tsx`：原生按钮用 AsyncButton，Ant Design 按钮用 AsyncAntButton。loading 期间只显示居中旋转的小圆圈，标签隐藏但保留占位；即使调用方在请求过程中改变文案，仍保留开始请求前的内容尺寸。disabled 与 aria-busy 同时生效，无障碍名称保持可识别。完成后由业务决定“已领取”、重试或普通文案。

余额刷新按钮原有转圈及最短展示时间保留；它旁边的余额省略号属于金额展示，不属于按钮文字。页面导航、弹窗开关、条件筛选、复制到剪贴板不作为接口提交按钮处理。宝箱按钮只打开领奖弹窗，提交请求在弹窗的领取按钮中处理。
