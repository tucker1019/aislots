# 大厅运营后台

独立的 React / TypeScript / Ant Design 工作台，只管理大厅业务。游戏机台管理不属于本项目。

## 本地启动

使用 Node.js 22.12 或以上版本，与 `slots_lobby` 保持相同依赖版本。

```sh
cd slots_lobby_admin
npm ci
npm run dev
```

入口为 http://127.0.0.1:5176 ，`/admin/api` 默认代理到 http://127.0.0.1:8082 。后台管理员需通过服务端 `./script/admin.sh bootstrap` 初始化，不内置默认口令。服务端需要允许开发入口的 Origin。

隔离视觉测试可以使用 `ADMIN_API_TARGET=http://127.0.0.1:8182 npm run dev` 指向只读测试服务。该选项仅影响开发代理，不进入生产包。生产环境由同源反向代理转发 `/admin/api`，不要将开发服务器暴露到公网。

## 已实现

- HttpOnly Cookie 会话登录、当前管理员、退出；会话失效清空 Query 数据。
- 大厅总览、游标分页会员查询与只读钱包/收款资料/近期账变。
- 充值和提现订单检索、状态筛选，以及需要理由的明确人工审核确认。
- 配置分区、递归结构化字段编辑、草稿保存、服务端校验、发布、版本历史和回滚。
- 审计游标查询。界面根据角色显示写入口，权限仍由服务端校验。

资金审核重试沿用相同 `requestId`；修改审核内容会生成新的标识。请求不自动重试。发布和回滚也使用显式确认及请求标识。订单金额使用整数字符串并按分精确格式化，不转为 JavaScript 浮点数。

配置编辑保持后端文档的字段与类型。数组根据配置分区预设模板添加或移除，删除全部后仍能恢复；游戏与代理提供商映射可新增、删除格式受限且不重复的标识。流水来源标识固定，仅允许编辑倍数。Banner 跳转选择站内路由。服务端负责字段约束与生效边界。草稿保存 CAS 使用 `max(publishedVersion, draftVersion)`；发布使用草稿版本，回滚使用当前发布版本。草稿保存与发布分离，未保存的表单切换页面前请先保存。

## 检查

```sh
npm run lint
npm run typecheck
npm test
npm run build
```

测试使用模拟接口，覆盖会话/数据校验、金额精度、审核必须确认、防重复提交以及失败重试幂等标识。没有对真实会员执行资金审核。

服务端启动与权限、审核、生效边界详见 `../lobby_service/docs/admin.md`。本地当前管理员登录信息由开发环境单独保管在用户私有目录；口令不进入仓库。
