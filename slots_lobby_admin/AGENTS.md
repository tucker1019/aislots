# 大厅运营后台开发约定

- 独立管理大厅业务；未来游戏后台另建项目。本项目不编辑机台赔率、盘面库，也不连接机台数据库。
- React/TypeScript/Ant Design；services集中请求及运行时响应校验，TanStack Query管理服务端数据，Zustand只管理界面状态。使用系统字体，保证中文控制台清晰易读。
- API仅走独立 `/admin/api`，HttpOnly会话，不能复用玩家uid/sid。前端角色控制只是展示，权限由后台校验。
- 请求按钮遵守仓库 `.agents/skills/async-button-states/SKILL.md`，保留原文案和尺寸，旋转图标、防重复提交；审核失败重试保留同一请求标识。
- 金额使用分的整数字符串，展示时精确格式化，不将大金额转为Number。业务配置中的JSON数字需安全整数。
- 查询列表用游标，标题与筛选使用公共Page吸顶区；只在列表显示加载/空态，失败可局部重试。
- 配置使用结构化字段、分区模板和受限map键，支持空数组恢复；流水来源键不可任意新增。草稿保存的expectedVersion为max(publishedVersion,draftVersion)，发布用draftVersion，回滚用publishedVersion。
- 资金审核和配置发布/回滚必须显式确认与原因；不自动重试写请求。真实资金操作不得用于UI验证，使用模拟服务或隔离数据库测试。
- 发布后的业务生效边界以服务端文档为准；反水按下个对应周期生效。图片填写已上传资源URL，本期不做文件上传。
- 本地开发5176，后台服务8082均默认本机；没有用户明确请求，不提交、不推送、不部署远程。
