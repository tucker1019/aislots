# AG6 金鼠规则与初始数值参考

本说明整理已确认的规则及1019常规开奖流程。AG6数值工具已接入，配置位于`game_configs/AG6`，使用说明和消费契约见该目录的`README.md`。

## 盘面与线奖

- 三列三行，共九格，五条中奖线：中排、上排、下排，以及两条对角线。
- 从最左列向右连续三个符号形成中奖。百搭替代任意普通符号；每条线只支付可成立的最高奖，不同中奖线相加。
- 普通赔付按单线投注计算：`奖金＝原始倍率合计×总投注÷5`。
- 例如总投注10元，每线2元，只中一条橘子线，奖金为`5×2＝10元`；同时中两条橘子线则为20元。

| Lua符号编号 | 图标 | 三连原始赔率 |
| --- | --- | ---: |
| 1 | 花生 | 3 |
| 2 | 橘子 | 5 |
| 3 | 鞭炮 | 15 |
| 4 | 钱袋 | 30 |
| 5 | 红包 | 50 |
| 6 | 金色鼠纹牌 | 100 |
| 7 | 老鼠百搭 | 300 |

全盘九格均为百搭时，按规则图支付**总投注1000倍**，替代普通五条线的奖金，不再叠加线奖。使用上述原始倍率单位时，此结果对应**5000**。

这项与Lua现有计奖不同：`room.lua`全盘百搭返回原始1000，最终乘单线投注，实际为总投注200倍。AG6以已确认的规则图为准。

## 一次投注的流程

一次付费投注选择普通开奖或特殊重转流程，扣一次总投注。

普通模式直接得到一个中奖或无奖盘面，结算后结束。

特殊功能触发后，中间一列固定三个百搭，左右两列重转，不增加投注。先展示若干无奖盘面，第一次中奖后支付奖金并结束；没有中奖后的追加重转，也没有盘面图标累计。

1019的实现先确定特殊功能最后支付的原始倍率，再安排前段无奖盘面，最后追加一个对应倍率的中奖盘面。触发该流程时，不先结算另外一笔普通奖金。它不是固定次数免费旋转，也不是每次重转都独立按特殊中奖率派奖。

例如总投注10元，前两次特殊盘面无中奖，各付0元；第三次只有一条橘子线中奖，支付10元，整局结束。

## 初始概率与倍率表

用户已指定概率和倍率表先参考Lua。采用实际运行的`game/service/qd/1019/room.lua`，不使用生成脚本`1019.lua`中不同的普通表，也不引入平台或玩家调控策略。

| 项目 | 运行代码参考值 | 数值工具中的含义 |
| --- | ---: | --- |
| 特殊功能触发率 | 1.4% | 一次付费投注选择特殊流程的概率 |
| 普通模式占比 | 98.6% | 没有触发特殊功能时进入普通模式 |
| 普通模式中奖率 | 约28% | 已选择普通模式后，出现正奖的概率 |
| 普通模式无奖率 | 约72% | 已选择普通模式后，生成无奖盘面 |
| 特殊功能整段中奖率 | 100% | 整段只有最后一个盘面中奖，前段均为无奖 |
| 整笔投注中奖率 | 约29.008% | `98.6%×28%＋1.4%×100%` |

普通原表共有313行，其中零倍率权重7200000，312个正倍率档权重合计约2800000，整体抽样范围10000000。正倍率从3到1300，即总投注0.6倍到260倍。

特殊原表共有268行，其中零倍率权重为0，267个正倍率档权重合计约10000000。正倍率也从3到1300，表示整段特殊功能最后一个中奖盘面的原始总倍率。

当前文件职责：

- `base.json`保存普通中奖的原始倍率及权重。原表零项分离为普通中奖率，保留正倍率档及原权重；不能再叠加一次表内零奖概率。
- `free.json`保存**整段特殊功能的最终中奖倍率及权重**。它不控制前段无奖盘面的数量，也不是每次特殊重转的独立派奖表。
- 特殊触发率、普通中奖率和前段无奖次数策略单独保存；图标生成权重只控制合法盘面的形态。

按Lua原表、常规概率及原始倍率单位计算：

```text
总返还率＝98.6%×普通模式期望原始倍率÷5
        ＋1.4%×特殊功能期望原始倍率÷5
```

该初始参考值约为**97.0253%**：普通部分约87.0253%，特殊部分约10.0000%。这是尚未增加原始5000大奖档的参考口径；全盘百搭档权重确定后，须重新计算实际AG6返还率。

Lua表权重有约百万分之一量级的十进制求和尾差；运行抽样范围为10000000，后续导入需记录此来源，不用骨架数量反推概率。这里的百分比按常规均匀抽样解释，不包含外部调控、查库缺档降倍率或回退空奖的影响。

## 全盘百搭大奖档的数值边界

现有Lua普通及特殊表均没有原始5000档。当前工具在两张表中显式加入原始5000档，初始权重为0，待数值调整时设定。生成器包含该档展示骨架；它不计入正权重倍率覆盖要求，初始不会被数值模拟抽中。

原始1000档仍需保留，不能整体改成5000。它也能由非全盘百搭组成：例如九格中只有左上角为红包，其余八格均为百搭，两条经过左上角的线各付50，另外三条纯百搭线各付300，合计`50＋50＋300＋300＋300＝1000`，对应总投注200倍。该结果与九格全百搭的1000倍总投注大奖是两个不同奖档。

原表没有收录的其他可达倍率不自动新增；开发时按正权重表逐档生成、验奖和检查覆盖。缺失或不可达倍率显式报告，不改权重、不降倍率、不回退空奖。

## 数值工具与后端职责

保持已有开发约定：中奖率和倍率权重直接控制奖金分布，开发页自行生成对应倍率的中奖骨架。普通与特殊中奖骨架分开，特殊骨架表示最后一个中奖盘面，中间整列百搭属于必要固定元素。

普通空奖、特殊前段空奖由后端实时生成；中奖骨架未固定位置由后端实时补齐。补空先排除会新增中奖的候选，再从合法候选抽一次，不重摇、不重抽、不回溯，不改变固定中奖元素或选中奖金。数值工具预览与重放沿用同一约束。

特殊前段无奖盘面无需保存为中奖骨架，也不通过生成频率、桶内条数或保留比例改变开奖概率。
