# AG8 金龙规则与数值口径

规则以用户提供的四张截图及后续确认为准；Lua 1048 仅提供初始倍率表、概率、底部倍率权重及五倍投注流程。八次免费全空依然完整展示八次，达到实际扣款2500倍时支付剩余额度并立即结束。

## 盘面与赔付

三列三行，按列从上到下编号1～9。五条线依次为 `[2,5,8]`、`[1,4,7]`、`[3,6,9]`、`[1,5,9]`、`[3,5,7]`。骨架位置为零基0～8。

图标1～7依次为铜钱、中国结、鞭炮、灯笼、红包、金元宝、金龙百搭；三连原始赔付分别为2、3、5、10、25、50、100。百搭替代全部普通图标，每线取最高奖，中奖线相加。同一种图标满盘没有额外加成，全百搭五线原始赔付500。

普通转底部为一个倍率，可出现空白（按1倍）、2、5、10。触发免费功能后直接进入八次免费，替代该笔普通结果。每次免费独立抽取2或3个倍率，每个倍率可为2、5、10，可重复，按和计算。例如2、5、5的合计倍率为12。每转图标清空，底部倍率和盘面符号都不跨转保留。

设实际扣款为 `投注额`，盘面五线原始赔付之和为 `盘面倍率`：

```text
普通投注：本次奖金 = 投注额 × 盘面倍率 × 底部倍率（或免费倍率之和）÷ 5
五倍投注：本次奖金 = 投注额 × 盘面倍率 × 底部倍率（或免费倍率之和）÷ 25
```

五倍模式实际扣款为普通模式五倍，单线奖金基准不提高；使用独立的普通、免费中奖率及倍率表。例如单线投注10分、等级1，普通实际扣50分，五倍实际扣250分；铜钱线原始2倍、底部5倍时，两者都支付100分。整局上限分别是实际扣款的2500倍。

免费逐次派奖。使用累计原始奖金换算金额后取整的差分，保证八次累计奖金及每线实付金额与钱包入账一致。达到封顶时只支付剩余额度，取消后续免费；未达封顶必须展示八次，包括八次全空。

## 初始数值与理论

初始配置来自 `slotCfg_1048.lua`，四张表各194个正倍率档，保留正奖权重，零项分离为中奖率。普通投注的普通转中奖率约22%、免费单转约28%；五倍投注两种结果中奖率均为100%。免费触发率0.66%。使用Lua表权重的实际总和归一化，不假设权重总和恒为10000或10000000。

| 权重项 | 数值与权重 |
| --- | --- |
| 普通转底部倍率 | 空白1：7000；2：1000；5：400；10：200，总和8600 |
| 免费倍率个数 | 2个：8800；3个：1200 |
| 免费单个倍率 | 2：4000；5：5000；10：1500，总和10500 |

理论先组合单次盘面倍率与底部倍率的完整分布，再卷积八次免费奖金分布，对总奖截断封顶。普通和免费按触发率混合：`总返还率＝(1－触发率)×普通平均实付倍率＋触发率×八次免费平均实付倍率`。所有倍率及返还率以实际扣款为分母；提前停止与最终合计截断的总奖金等价。

当前普通投注理论约97.0019028%，五倍投注约97.0012512%；模拟使用相同配置，固定种子可重现。频谱卷积补零至完整八次分布支持范围，避免高奖回绕。理论为连续投注单位下的期望，不含具体投注金额的分币取整。

## 骨架与补空

普通库与免费库每条骨架都表示一次中奖转，仅固定决定五线奖金所需的图标，不包含底部倍率、投注额、余额或完整八次免费。桶键是尚未乘底部倍率的原始盘面倍率，每库覆盖对应普通及五倍表的正权重档并集。骨架数量、形态权重和生成耗时不参与中奖率及返还率计算。

开发页使用固定种子安排七种图标的枚举顺序，遍历最多 `7^9＝40353607` 个盘面；全档覆盖后额外枚举十万次，或达到次数、容量上限时结束。支持工作线程进度、停止保留完整骨架、每倍率上限、总容量和缺档报告。

实时空奖从九个空格开始构造，中奖则按配置抽倍率、选骨架、逐格补齐。每格从六种普通图标中排除会新增中奖线的候选，然后只抽一次。每格至多涉及五条线，每条线至多排除一种普通图标，至少剩一种合法候选；预先拒绝两个百搭加空格的不可补形态。补后重新验奖，固定格、原中奖线和倍率必须完全一致。不重摇、不回溯、不替换倍率或骨架。

两库各580条，分别覆盖194/194正权重档，不包含零奖桶。候选保存检查数值与盘面两份版本，独立新建批次；Go发布时再次独立验奖和核对覆盖，再创建不可变快照。详见[配置说明](../../game_configs/AG8/README.md)、[Go模块](../../slots_service/internal/games/ag8/README.md)。
